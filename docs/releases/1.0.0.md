# 1.0.0 release candidate

Status: draft review candidate; not released. Candidate live provider/relay acceptance remains pending.

Buzz Agent Bridge now separates durable lifecycle code from Buzz source/receipt
verification and ChatGPT Dot wake-up. It remains one package with the existing
Dot, MCP contract and compatibility imports. No independent connector SDK or
additional provider is advertised.

Breaking: incoming direct replies are accepted and root-only markers are treated
as top-level, matching official Buzz thread semantics. Fresh signed source evidence
is used for pending publication and reconciliation without rewriting history.
Follow the [migration](migration-1.0.md); mixed-version operation and an unchecked
downgrade are unsupported. This is a strict major change from 0.2.0.

Other changes: require explicit signed readback at the broker delivery boundary;
preserve uncertainty with no retry; cache callback verification for five minutes;
support a five-minute old/new webhook-signing overlap on refresh; make permission
fixtures independent of umask; add portable build/clean-install CI and a GitHub
Issue/Conventional Commits/SemVer skill distribution for separate user-level installation.

See [validation](../project/validation.md) for commands, upstream revisions,
artifact results and unexecuted gates. Product publication, work tags and remote
links must be filled by the authorized Alita App session after review. No PyPI
release is proposed. Existing MIT license and public history are preserved.
